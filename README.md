# Derive

A bilingual, art-led introduction to Derive: a living atlas connecting city streets with the films, books, artists and ideas rooted in them.

## Run locally

```sh
npm install
npm run dev
```

## Build for Vercel

```sh
npm run build
```

Vercel can deploy this Vite app with the default settings: build command `npm run build`, output directory `dist`.

The Paris atlas, check-ins, notes and contact form are front-end demonstrations. Check-ins and saved notes persist in local browser storage; connect the contact form to a mailing-list provider or serverless endpoint before collecting real contacts. Photography is loaded from Unsplash and fonts from Google Fonts.
